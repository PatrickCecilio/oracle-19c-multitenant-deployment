# Portfólio SQL Server — Patrick Cecílio

Coleção técnica organizada de acordo com competências explicitamente registradas no currículo e profile profissional de Patrick Cecílio.

## Escopo profissional validado

- Microsoft SQL Server e SQL Server Management Studio (SSMS)
- SQL Server Agent e Jobs
- Backup e Restore
- Execution Plans e Query Store
- Missing Index, Statistics e manutenção de índices (Rebuild/Reorganize)
- SQL Server Profiler, Extended Events, monitoramento, diagnóstico e performance
- Replication

| Área | Conteúdo |

| [Performance-Execution-Plans](Performance-Execution-Plans) | Análise de desempenho e planos de execução armazenados em cache. |
